Configuración y sincronización

🔗 Sincronización (opcional)

Sin configurar nada, la app guarda todo en este dispositivo. Si quieren ver lo mismo en los dos celulares, configuren Supabase (gratis) abajo.

Modo local activo

Activar sincronización entre dispositivos (gratis)

  1. Entrá a supabase.com y creá cuenta gratis
  2. Creá un proyecto nuevo
  3. Storage → New bucket → nombre: couple-files → Public bucket
  4. SQL Editor → pegá y ejecutá:
create table if not exists shared_items (
  id text primary key,
  couple_code text not null,
  type text not null,
  name text,
  url text not null,
  created_at bigint
);
create index if not exists idx_couple on shared_items (couple_code);
alter table shared_items enable row level security;
create policy "permitir todo" on shared_items for all using (true) with check (true);
  1. Project Settings → API → copiá URL y anon key
