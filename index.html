🔗 Sincronización

Ambos deben poner el mismo código de pareja para ver lo que sube el otro en tiempo real.

Estado: no conectado

Cómo activar la sincronización (gratis, una sola vez)

  1. Entrá a supabase.com y creá una cuenta gratis
  2. Creá un nuevo proyecto (elige la región más cercana)
  3. Cuando esté listo, andá a Storage → New bucket → nombre: couple-files → marcá Public bucket
  4. Andá a SQL Editor → New query y pegá esto, luego Run:
create table if not exists shared_items (
  id text primary key,
  couple_code text not null,
  type text not null,
  name text,
  url text not null,
  created_at bigint
);

create index if not exists idx_couple on shared_items (couple_code);

alter table shared_items enable row level security;

create policy "permitir todo" on shared_items
  for all using (true) with check (true);
  1. Andá a Project Settings → API
  2. Copiá el Project URL y la clave anon public
  3. Pegálos abajo y tocá Guardar

Esto se guarda solo en tu navegador. La otra persona también debe pegar la misma URL y la misma clave.
